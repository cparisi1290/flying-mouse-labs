# Silver Tree - Business Consulting Website

A modern, responsive business consulting website built with HTML5, CSS3, and vanilla JavaScript.

## 🚀 Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Hero Section**: Eye-catching landing area with call-to-action buttons
- **Services Section**: Showcase of business consulting services
- **Who We Help**: Target audience cards with hover effects
- **Testimonials**: Client testimonials with navigation
- **About Section**: Company story and mission
- **Trust Badges**: Recognition and awards display
- **Call-to-Action**: Conversion-focused CTA section
- **Newsletter Signup**: Email subscription with consent checkbox
- **Social Links**: Integrated social media profiles

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with CSS Grid, Flexbox, and animations
- **JavaScript (Vanilla)**: Interactive elements and smooth scrolling
- **Google Fonts**: Poppins and DM Serif Display typography
- **Font Awesome**: Icon library
- **Unsplash**: High-quality stock images

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Local web server (optional, for development)

### Installation
1. Clone the repository:
   ```bash
   git clone git@github.com:cparisi1290/silver-tree.git
   cd silver-tree
   ```

2. Open `index.html` in your browser or serve with a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

3. Visit `http://localhost:8000` to view the website

## 🔧 Customization

### Colors
Edit the CSS variables in `main.css`:
```css
:root {
    --copper: #CC9466;
    --deep-plum: #664875;
    --plum: #9b7eac;
    --blue: #a2bae6;
    /* ... other colors */
}
```

### Images
Replace images in the `assets/images/` directory:
- `hero-coffee-chat.jpg` - Hero section image
- `experts-coffee-chat.jpg` - About section image
- `silver-tree-right.png` - Background decoration
- Service images for each offering

### Content
Edit text content directly in `index.html`:
- Headlines and descriptions
- Service offerings
- Contact information
- Social media links

## 🌐 Deployment

### Static Hosting
The website can be deployed to any static hosting service:
- **Netlify**: Drag and drop the folder
- **Vercel**: Connect GitHub repository
- **GitHub Pages**: Enable in repository settings
- **Surge.sh**: `surge` command in project folder

### Custom Domain
Update the base URL if deploying to a custom domain:
```html
<base href="https://yourdomain.com/">
```
